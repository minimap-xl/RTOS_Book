# Concurrent Programming Exercises on the ESP32 #

This directory contains the source code of the answers to some exercises
proposed in Chapter 8 of the book.

The source code does not contain Doxygen documentation, but the embedded
comments provide information on technical details.

Please refer to the documentation of the [CAN/UDP
Gateway](https://bitbucket.org/minimap_xl/rtos_book_gateway/src/main/case_studies/gateway/)
for more information on how to build the firmware, upload it to an ESP32 board,
and execute it.
