# Real-Time Embedded Systems, Open-Source Operating Systems Perspective #

This repository contains the accompanying software of the book *"Real-Time
Embedded Systems, Open-Source Operating Systems Perspective"*, by Ivan Cibrario
Bertolotti and Gabriele Manduchi, 2nd Edition, CRC Press, Taylor & Francis
Group, 2025.  In particular:

  * The subtree at [case_studies](case_studies) contains the source code
    of the three case studies discussed in the book.

  * The subtree at [exercises](exercises) contains the solution to some
    programming exercises.


The authors welcome comments, critics and suggestions from readers, using the discussion form of this repository.
